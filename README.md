# 🚗 Used Car Price Prediction App

## 📌 Overview

This project is a **Used Car Price Prediction Web Application** built using **Streamlit**. It predicts the resale price of a used car based on various features such as year, fuel type, transmission, and more.

The project demonstrates the complete **Data Science workflow**, including:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Model Building using Linear Regression
* Deployment with Streamlit

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Libraries Used:**

  * NumPy
  * Pandas
  * Seaborn
  * Matplotlib
  * Scikit-learn
* **Web Framework:** Streamlit

---

## 📊 Features

* Interactive UI for user input

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/used-car-price-prediction.git
cd used-car-price-prediction
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the App

```bash
streamlit run app.py
```
